The weather processing infrastructure for the fictional island of Marrow Bay

Core Software Frameworks

1. SGAWPS (SGA Weather Processing System)

The "sender" framework of the database responsible for providing fast weather models to forecasters. Originally rooted in Suwanee, Georgia, the system is transitioning its operational jurisdiction to Marrow Bay (updating the station identifier from SGA to MRB in future builds). This framework contains:

  • sgawps_tw.exe: The Text Workstation used by forecasters to create, edit, and distribute forecast messages (Warnings, Watches, Advisories, non-weather emergency messages, etc.). It hosts the Broadcast Message Handler (BMH) client to control all station servers.
  • sgawps_awips.exe: The client application that loads Marrow Bay geographical data, CONUS radar data, and storm rotation information, allowing forecasters to create storm-based polygons and send them to WarnGen.

2. SGAIEM (Suwanee Georgia Iowa Environmental Mesonet)

The "receiving" end of the database. It receives messages sent from SGAWPS and distributes them out to the BMH system, the WwA system, local officials, and the general public. It is slated to be renamed to Suwanee Georgia Integrated Emergency Manager in upcoming software builds.

Simulated NOAA Weather Radio Stations

  • WXK39 (South Atlanta, Marrow Bay): Serves the western half of Marrow Bay and adjacent coastal waters. Operates on 162.475 MHz via a wireless audio feed.
  • KBB56 (North Miami, Marrow Bay): Serves the eastern side of Marrow Bay and adjacent waters. Operates on 162.425 MHz via a wireless audio feed.

In Development: MarrowBayWX

A significant weather monitoring application specifically designed for Marrow Bay in the west-central Atlantic. Built using a TypeScript/TSX frontend with AI collaboration, MarrowBayWX will notify users of critical warnings for specific counties, stream live radar data, and display storm polygons. Web, iOS, and Android applications are planned for public domain release once key bugs are resolved.
